## K4. Окно «Мод»

Дерево файлов, таблицы по схеме с «база / мод / итог», конфликты, проблемы, предпросмотр юнита/экрана/кадра.

## K5. Горячая перезагрузка

`ContentWatcher`, `--watch`. Приёмка: сцена с `--watch --check` меняет файл строки мода и печатает `reload screens=… strings=…`
без перезапуска; изменение таблицы правил печатает `reload rules=restart-needed`.

## Риски

| Риск | Последствие | Мера |
|---|---|---|
| слой правил затронет харнессы | ложные расхождения С1/С2/Ф7 | харнессы читают базу явно; тест «с модом графики — те же числа» |
| загрузчики читают таблицы в 30+ местах строкой каталога | пропущенное место читает базу при включённом моде | K0.2: поиск `GameTables.Read(` по дереву, тест «мод меняет каждую из 31 таблицы — загрузчик видит» |
| схема с неверным смыслом колонки | модер вводится в заблуждение | у каждого `meaning` — источник; неуверенное помечать «гипотеза» |
| конфликты id модов | два мода — один `g9…` | реестр приставок или хэш `id` (вопрос пользователю) |
| моды меняют экран, ломая логику | окно не открывается | `MOD030` + `MapScreen.DropFailed` уже есть |
| сохранения с модами | несовместимость при смене набора | K3.2 |
