# Моддинг: спецификация

Правила формата — [`../data-contract.md`](../data-contract.md). Что есть сейчас — [`docs/modding.md`](../../modding.md).
Номера правил проверки — `MODnnn` (§9).

## 1. `mod.json` v2

```json
{
  "id": "example-new-unit",
  "name": "Пример: новый юнит",
  "description": "…",
  "version": "1.2.0",
  "format": 2,
  "game": ">=0.9",
  "authors": ["…"],
  "dependencies": [{"id": "port-synth", "version": ">=1.0"}],
  "conflicts": ["other-mod"],
  "loadAfter": ["some-mod"],
  "languages": ["ru", "en"]
}
```

- Без `format` — v1 (как сейчас: `id`, `name`, `description`); читается всегда.
- Порядок наложения: сначала граф `dependencies`/`loadAfter` (топологически), при равенстве — как сейчас (корень, затем имя
  каталога). Цикл — ошибка `MOD002` с путём цикла.
- Нет зависимости → мод не включается, строка запуска `mods:` пишет `skipped=<id>(нет <dep>)`; молча не пропускать
  (как сейчас для сломанного `mod.json`).
- `game` — версия формата данных порта (вопрос пользователю: завести номер версии порта — рекомендация: `data/version.json`
  `{ "data": 1 }`, растёт при несовместимой смене любого формата).

## 2. Слой правил (главный пробел)

Сейчас: `GameBook.Load(rulesDir)` → `GameTables.Read(dir, "Gunits.dbf")` — один каталог `data/rules`, 31 таблица
(`Gunits`, `Gattacks`, `GItem`, `Gspells`, `Gbuild`, `GbuiList`, `GcityInf`, `Gimmu`, `GimmuC`, `Gmodif`, `GmodifL`, `GleaUpg`,
`GDynUpgr`, `Gtransf`, `Glord`, `Grace`, `GspellR`, `GLmark`, `GLabi`, `GMabi`, `GVars`, `GAI`, `Gaction`, `LAttR`, `LattC`,
`LattS`, `LleadA`, `LmagItm`, `LDthAnim`, `TAiMsg`, `Tleader`). Формат: `{table, columns[{name,type,length,decimals}], rows[]}`.

Нужно: `<мод>/data/rules/<Имя>.json` — **наложение строк по первичному ключу** таблицы.

```json
{
  "table": "Gunits",
  "rows": [
    { "UNIT_ID": "g000uu0001", "HIT_POINT": 140 },
    { "UNIT_ID": "g900uu0001", "UNIT_CAT": 0, "LEVEL": 1, "…": "… все колонки новой строки …" }
  ],
  "remove": ["g000uu0099"]
}
```

| Случай | Поведение |
|---|---|
| ключ есть в базе | меняются только указанные колонки (вопрос пользователю: построчно-поколоночно (рекомендация, как Object Editor WC3) или строка целиком) |
| ключа нет | новая строка; все обязательные колонки схемы — иначе `MOD020` |
| `remove` | строка убирается; ссылки на неё в других таблицах и сценариях — `MOD021` |
| таблица без ключа (`GVars` — одна строка, `GAI`) | правка колонок единственной строки / по составному ключу из схемы |
| `columns` в моде | не нужны: берутся из базы; новая колонка — только вместе с кодом правил (П3), `MOD022` |

Ключи — регистр не значим (в данных `g000uu0001`, в сценариях `G000UU0001`). Новые id модов — своя приставка, чтобы не
столкнуться с базой и другими модами: рекомендация — `g9xx…` с `xx` из реестра в `docs/modding.md` (вопрос пользователю:
реестр приставок или хэш `id` мода).

Реализация — см. [`architecture.md`](architecture.md) §2: `GameTables` получает список каталогов слоёв, кэш по ключу
«набор слоёв + время записи».

## 3. Схема таблиц

`data/rules/schema/<Имя>.schema.json` (в базе, генерируется один раз из `.dbf` + ручная разметка):

```json
{ "table": "Gunits", "key": ["UNIT_ID"],
  "columns": {
    "UNIT_ID":   { "type": "id", "meaning": "Тип юнита" },
    "UNIT_CAT":  { "type": "enum", "ref": "LUnitC", "meaning": "Категория: 0 солдат, 1 вор?, 2 лидер…" },
    "ATTACK_ID": { "type": "ref", "ref": "Gattacks", "meaning": "Первая атака" },
    "NAME_TXT":  { "type": "text", "meaning": "Имя (строка в strings.<яз>.json)" },
    "HIT_POINT": { "type": "int", "min": 1, "max": 9999, "meaning": "Здоровье" } } }
```

**Вопрос пользователю** (имена колонок): оставить колонки как в `.dbf` + схема с `meaning` (рекомендация: моды и импорт не
ломаются, харнессы сверяются с таблицами игры напрямую) или перевести формат на имена по смыслу (`hitPoints`) с переводчиком
старых модов. Принцип «имена по смыслу» здесь выполняется схемой и окном «Мод» (показывают `meaning`), не файлом.

## 4. Интерфейс

Как сейчас: экраны заменяются целиком по `Id` и **обязаны сохранить все элементы базы** (тест
`GameContentTests.DefaultMods_KeepEveryElementOfReplacedScreens`, проверка `MOD030`); новые экраны — только с логикой в коде
(окно без `IScreenLogic` показывается по разметке). Граф `flow.json`, `defaults.json`, `transitions.json` — как сейчас.
Отрицательные примеры для проверок — `tools/ui-check-mods/` (`broken-action-result`, `self-goto`).

## 5. Графика и анимации

Описи `data/gfx/<Архив>.json` (`images`, `anims{name,dir,ext,w,h,frames,at,sha256}`), кадры интерфейса `data/ui/assets.json`;
файлы в `<мод>/assets/gfx|ui`, PNG или WebP без потерь с `exact`. Проверки: файл есть (`MOD040`), размер = опись или кратен ей
для HD (`MOD041`, предупреждение), магента в кадрах мода (`MOD042`, предупреждение — мод её не вырезает), имя анимации юнита
по шаблону боя `{база}{действие}{A|S}{слой}{A|D}00` (`docs/battle-render.md`) для новых юнитов (`MOD043`). Новому юниту нужны:
лицо (`Faces`), значок карты (`IsoUnit`), анимации боя (`BatUnits`) — список требуемых имён строится из `UNIT_ID`.

## 6. Звук

Нужно: слой `data/sound/*.json` (`AudioRgn`, `Battle`, `Midgard`, `Music`, `UnitSounds`) по имени, как `UiVideos.Merge`;
файлы в `<мод>/assets/sound`. Проверка `MOD050` — файл есть и читается.

## 7. Переводы

Строки `strings.<яз>.json` (по id, запасной `en`), имена из таблиц (`NAME_TXT`/`DESC_TXT` → id строки), переводы сценариев
`data/scenarios/lang/<яз>/`. Проверки: у нового id таблицы нет строки ни в одном языке мода (`MOD060`, ошибка), нет в языке
из `languages` (`MOD061`, предупреждение). Отчёт `d2mod texts --missing ru`.

## 8. Сценарии и кампании

Карты — рабочее пространство «Карта» ([`../map-editor/spec.md`](../map-editor/spec.md)); в моде: `data/scenarios/*.json`,
карточки `data/game/scenarios.json`, кампании `data/game/campaigns.json` (слой по `Id` уже есть — `GameCatalog.Merge`). Карта мода, ссылающаяся на юнит мода, — зависимость (`MOD070`, если карта лежит в
другом моде без `dependencies`).

## 9. Проверка мода (`d2mod validate`)

| Id | Уровень | Что |
|---|---|---|
| MOD001 | error | `mod.json` не читается, нет `id`, `id` повторяется |
| MOD002 | error | цикл зависимостей; MOD003 — нет зависимости; MOD004 — конфликт включён |
| MOD010 | error | JSON файла слоя не читается (файл, строка, столбец) |
| MOD020–022 | error | строки таблиц: нет обязательных колонок, удалена строка со ссылками, новая колонка |
| MOD023 | error | ссылка `ref` указывает в пустоту (по схеме, во всех слоях) |
| MOD024 | error | значение вне `min/max` или не того типа |
| MOD030 | error | заменённый экран потерял элемент базы |
| MOD040–043 | error/warning | графика (§5) |
| MOD050 | error | звук |
| MOD060–061 | error/warning | строки (§7) |
| MOD070 | error | сценарии мода: `d2mod map check` для каждого, зависимости |
| MOD090 | error | пробная загрузка: `GameContent.Load` + `GameBook.Load` с модом без исключений, `NewGame.Start` на первом сценарии |

Итог: `mod=<id> files=N errors=E warnings=W`, код 0 при `E=0`.

## 10. Сборка и упаковка

`d2mod pack <каталог>` → `<id>-<version>.zip`: `mod.json`, `data/`, `assets/`, `manifest.json`
(`{file, size, sha256}` по каждому файлу), без `.studio/`, `.git`. `d2mod install <zip>` → `user://mods/<id>` (отказ, если
каталог есть и версия не новее — `--force`). Проверка перед упаковкой обязательна (`validate`).

## 11. Совместимость и версии

- Формат данных порта меняется → `data/version.json` растёт, у каждого формата своя `Version` и чтение старых версий
  (как `ScenarioFile` v5, сохранения v10). `d2mod migrate` переводит мод на новый формат (как `OpenRA.Utility`).
- Сохранение партии хранит список модов с версиями; загрузка с другим набором — предупреждение (вопрос пользователю:
  запрещать или предупреждать; рекомендация — предупреждать).

## 12. Горячая перезагрузка

| Что | В идущей игре | Как |
|---|---|---|
| экраны, кадры, строки, шрифты | да | пересобрать `GameContent`, открытые экраны перерисовать по `UiScreenState.Revision` |
| графика мира и боя | да | сбросить кэш текстур (`GfxTextures`), куски земли (`GroundChunks.Refresh`) |
| звук | да | сбросить кэш |
| таблицы правил | **нет** — перезапуск партии | `GameBook` неизменяем в партии; смена посреди партии расходится с сохранением |
| сценарий | нет — перезапуск партии с карты | — |

Сигнал — файл `<мод>/.studio/reload` или `--watch` у игры; сейчас горячей перезагрузки нет совсем.

## 13. Запуск игры с модом

`d2mod run [--mod <каталог>] [--only] [--scenario <Id> --player <PlayerId>] [--lang ru]` → `godot --path godot <сцена> --
--mods <корень> …`. `--only` — только этот мод и его зависимости (временный корень-список; нужна поддержка `--mods a;b` —
уже есть). Строка `mods:` в журнале сверяется с ожидаемым набором.
