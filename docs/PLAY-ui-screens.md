# Прогон с зондом: срез экранов интерфейса

Цель — открыть экраны, которых ещё нет в графе экранов порта (`data/ui/flow.json`: из 132 не открывались 49,
список — `docs/ui-flow.md`, «Покрытие»), и записать, как ведёт себя меню там, где порт сделан по догадке.
Каждый открытый экран даёт переходы в граф без ручной работы: после прогона журнал разбирает
`dotnet run --project tools/UiFlowImport`.

Всего четыре захода, по 10–20 минут; их можно играть в разные дни, в любом порядке. Партии не нужно
доигрывать — нужно открыть окна.

## Перед началом (один раз)

- Зонд уже стоит: `game-dev`, схема 7.1.1, сборка `490172a`, таблицы игры штатные (проверено 19.09:
  `python tools/d2probe/install.py --status` из `disciples-godot`). Ничего ставить не нужно.
- Запуск записи — PowerShell, из корня `disciples-modding`, **один раз на весь заход**:

  ```
  python tools\gamedrv\passive_run.py --out ..\disciples-godot\corpus\20260920-ui
  ```

  На следующие заходы — тот же каталог или новый (`20260921-ui` и т. д.), неважно.
- Главное правило: **открыть окно и закрыть его той кнопкой, которой обычно закрываете**; где у окна две
  кнопки («ОК» и «Отмена») — по возможности открыть дважды и нажать обе.
- Окно не открылось, открылось не то, игра упала — запишите одной строкой. Это тоже ответ.
- Сохраняться не обязательно: здесь важен журнал, а не сохранения.

## Заход 1. Меню (10 минут, без партии)

| № | Что сделать | Что должно открыться |
|---|---|---|
| 1 | Одиночная игра → **Новая сага** | выбор кампании (`DLG_CHOOSE_CAMPAIGN`). Запомнить, какой ролик сыграл при переходе |
| 2 | Там же: выбрать кампанию → «Продолжить» до экрана лорда → кнопка **«Импортировать героя»** | окно импорта героя (`DLG_IMPORT_LEADER`); закрыть «Назад»/«Отмена» |
| 3 | Одиночная игра → **Новая своя кампания** | какой ролик сыграл? (в журнале экран уже есть) |
| 4 | Одиночная игра → **Новый квест**: щёлкнуть строку списка **один раз**, затем другую — **двойным щелчком** | двойной щелчок начинает игру или только выбирает строку? |
| 5 | Там же: какой сценарий **первый** в списке и **как выделена** выбранная строка | записать |
| 6 | Там же: выбрать «Fardale's Web» (в ней эльфы) | какой **значок у эльфов** в ряду значков рас под списком? |
| 7 | Мультиплеер → по очереди **каждый** протокол → в каждом нажать **все кнопки, которые открывают окна** («Создать», «Присоединиться», «Загрузить»), потом «Назад» | экраны `DLG_HOST`, `DLG_LOBBY`, `DLG_LOAD_SKIRMISH` — что откроется без сети. Если что-то зависнет в ожидании сети — «Отмена»/Esc |

## Заход 2. Закладки постройки четырёх рас (15 минут)

Закладки постройки открывались только у Кланов. Нужны Империя, Нежить, Легионы, эльфы. Сценарии —
штатные из списка «Новый квест».

| Партия | Сценарий | Раса | Лорд |
|---|---|---|---|
| 2а | Power to Corrupt | Империя | любой |
| 2б | Power to Corrupt | Легионы | любой |
| 2в | Power to Corrupt | Нежить | любой |
| 2г | Fardale's Web | Эльфы | любой |

В каждой партии, в первый день:

1. Открыть **столицу** → **Строительство** → пройти **все пять закладок** (бойцы, лучники, маги, особые,
   прочие) → закрыть город.
2. Только в партии 2а, дополнительно:
   - **правой кнопкой** — по вражеской столице или её знамени (окно игрока, `DLG_R_C_PLAYER`);
   - открыть окно своего героя → **правой кнопкой по значку умения** (окно умения, `DLG_R_C_LEADERABIL`);
   - в окне героя — посмотреть **опыт лидера**, если там есть такая кнопка (`DLG_VIEW_EXPLEAD`);
   - Настройки → включить **«Сводка хода»** → «Конец хода» → должна открыться сводка (`DLG_TURNSUMMARY`),
     закрыть её.
3. Выйти в главное меню (Настройки → «Выход» или Esc → «В главное меню»).

## Заход 3. Синтетические карты — вор, гробница, жезл, посох, сумка (25 минут)

Все карты уже лежат в списке «Новый квест». Подробные памятки к ним — `disciples-modding/docs/synthetic-maps/<карта>/player-memo.txt`;
здесь нужно не то, что они проверяли тогда, а только окна.

**3а. `ai-t08a-rod-code7`** — Эльфы, лорд любой.
1. Отрядом «K» (клетка (36, 11)) напасть на нейтрала на (34, 13) и победить (бой любой, можно автобой).
   На месте нейтрала появится **гробница**.
2. **Правой кнопкой** по гробнице, затем зайти на неё отрядом «K», если игра пустит (`DLG_TOMB`).
3. **Правой кнопкой** по руине (клетки 33…35 × 15…17) — окно руины (`DLG_R_C_RUIN`).
4. **Правой кнопкой** по вашему жезлу на (27, 14) — окно жезла (`DLG_R_C_ROD`).
5. Отрядом «K» или Sage дойти до **мешка** на (37, 17) — окно подобрать/бросить (`DLG_PICKUP_DROP`):
   подобрать; потом в окне отряда бросить что-нибудь на землю, если есть кнопка.

**3б. `ai-q43-thief-warrior-lord`** — Империя, лорд **Гильдмастер** (Мастер гильдии).
1. Вор 2 на (13, 14) → щёлкнуть по деревне эльфов Elf E → в списке выбрать **«Украсть заклинание»** —
   должно открыться окно выбора заклинания (`DLG_STEAL_SPELL`). Выбрать любое или «Отмена».

**3в. `ai-g2-thief-riot`** — Империя, лорд **Гильдмастер**.
1. Вор 1 на (11, 16) → по деревне Riot A → **«Мятеж»**.
2. Вор 2 на (13, 14) → по той же деревне → свиток «Пока город бунтует…» (`DLG_THIEF_NOACTIONS`) → закрыть.

**3г. `ai-q34-staff-refusals`** — Империя, лорд **Воитель**.
1. Отряд «маг» на (19, 19) → **применить посох A** (Staff of Thunder) по нейтралу на (21, 21) — какое окно
   открывается при применении (`DLG_WAND_SCROLL`?). Нейтрала **не атаковать**.

**3д. `ai-q30-equip-refusals`** — Империя, лорд любой.
1. Герой 1 на (12, 19): в его сумке **свиток** (Air ward scroll) — **применить** его (не надевать) — какое
   окно открывается.

## Заход 4. «Горячий стул» (5 минут)

Главное меню → Мультиплеер → «Горячий стул» → «Новая схватка» → **`ai-q47b-hotseat-refuse`**. В лобби
Империя — человек, эльфы — человек.

1. Империя: «Конец хода». Между ходами игроков должно появиться окно передачи хода (`DLG_HOTSEAT_POPUP`) —
   закрыть. Эльфы: «Конец хода». Хватит двух-трёх передач.

## Что записать словами (одним сообщением после заходов)

1. Какой ролик играл при **Новой саге** и при **Новой своей кампании**.
2. Двойной щелчок по строке списка сценариев — начинает игру или нет.
3. Первый сценарий в списке; значок эльфов в ряду рас.
4. Какие окна из заходов **не открылись** или открылись не так.
5. Всё, что выглядело не так, как вы помните по игре.

## Чего в этой памятке нет и почему

- **Конец сценария** (`DLG_END_WIN_LOSE_`, `DLG_COMMON_RECAP`) и **конец главы кампании**
  (`DLG_CARRY_ITEM_LEADER`, `DLG_FAKE_CARRY_OVER`): до них долго играть. Если нужны, я соберу синтетическую
  карту с быстрой победой — скажите.
- **Сетевые экраны игрового сервера** (`DLG_CUSTOM_LOBBY`, вход, регистрация, пароль комнаты): нужны сервер и
  сеть; порту не нужны.
- `DLG_R_C_TRANSFORM`, `DLG_LEADER_PICKER`, `DLG_ISO_LAND`, `DLG_ISO_CAPITAL`: не знаю точно, где они
  открываются. Если встретятся по дороге — хорошо; искать специально не нужно.
