# Памятка: партия с зондом 7.2 — данные ИИ для остатка расхождений (30.09)

Одна пассивная партия (~30 мин) закрывает семь вопросов сразу — всё пишет зонд, от вас только «Конец хода» и сохранение.
Что пишет зонд и зачем — `docs/corpus-schema.md`, раздел «Схема 7.2».

| Вопрос | Событие журнала | Что есть на карте |
|---|---|---|
| Почему у ИИ нет торговца/мага/тренера в дни 1–4 | `ai_place_cache` (кошелёк тактики, места кэша с причиной отбора) | маг рядом с ИИ; в прошлой партии кандидаты мага появлялись только с дня 5; у ИИ по 5000 золота |
| Почему крепость не попадает в кэш целей | `ai_fort_cache` (фильтр, охрана, радиус, исключения по каждой крепости) | деревни и столицы трёх ИИ, гости в крепостях |
| Своя сила B по юнитам | `ai_strength_units` | нападения ИИ друг на друга с дня 1 |
| Регенерация в начале хода | `regen` (каждое слагаемое лечения) | раненые после боёв, гарнизоны деревень |
| Юнит в гарнизоне деревни не повышается | `upgrade_target` | `UN0019` (день 11) и `UN0014` (день 17) в `FT000c` — те самые случаи |
| Равноценные пути (колонка или зигзаг) | `path_expand` (порядок раскрытия узлов A*) | все ходы ИИ |
| Порядок id новых отрядов и юнитов | `id_alloc` | наймы и новые лидеры ИИ |

## Перед началом

Зонд — сборка 7.2 (ставит сессия до партии). Проверка после запуска записи — не нужна вам: сессия проверит строку `start`.

Запуск записи — из `C:\Claude code projects\disciples-modding`:

```
python tools\gamedrv\passive_run.py --out ..\disciples-godot\corpus\20260930-probe72
```

(если играете не 30.09 — поставьте в имя каталога свою дату, `ГГГГММДД-probe72`).

## Партия

Карта **ai-q09-ai-ai-diplomacy** — та же, что в части 5 памятки снимков (28.09), по её памятке
(`../disciples-modding/docs/synthetic-maps/ai-q09-ai-ai-diplomacy/player-memo.txt`):

1. «Одиночная игра» → «Новая схватка» → **ai-q09-ai-ai-diplomacy**, раса **Империя**, лорд любой, сложность **Нормальная**.
   Окна сценария на первом ходу закрыть.
2. Сразу сохраниться.
3. Дальше только **«Конец хода»** и сохранение в начале каждого своего хода — **до дня 20 включительно**.
4. Из столицы не выходить, ни на кого не нападать, ничего не предлагать и не дарить, города не захватывать, в дипломатии
   ничего не менять. Сообщения игры — записать (день, первые слова).
5. После сохранения дня 20 — закрыть игру (запись остановится сама).

Если ИИ осадил столицу и игра кончилась раньше — остановиться, сохранения уже есть. Если игра упала — записать день и что было на
экране, журнал останется в каталоге; дальше не играть.

## Что прислать

Одним сообщением: «сыграно до дня N», каталог прогона (`corpus\ГГГГММДД-probe72`), список сообщений игры (день — первые слова) и
что пошло не так. Разбор — у сессии: `python tools/d2probe/tests/probe_json_check.py <журнал>`, затем харнессы ИИ по партии
(`CorpusRow` новой партии рядом с `20260928-shots`).
