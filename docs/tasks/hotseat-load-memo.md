```
python tools\gamedrv\passive_run.py --out ..\disciples-godot\corpus\20260929-hotseat
```

**F12** — снимок (мышь перед снимком увести на правую панель). Одно окно — один F12.

Карта — штатная **Mercantile** (48×48, Империя и Эльфы). Главное меню → «Мультиплеер» → «Горячий стул» → «Новая» → Mercantile →
в лобби **обе расы — человек**, имена любые, золото и ману не трогать, сложность нормальная.

## Часть 1. Загрузка (20 мин)

1. Играть за обе стороны, пока лидер Империи не получит уровень в бою (бой с нейтралами у столицы; после боя — сообщение о росте
   уровня). **В этот же ход, до «Конца хода»**, сохраниться: «hs-load».
2. Выйти в главное меню. «Мультиплеер» → «Горячий стул» → «Загрузить» → «hs-load».
3. После брифинга — **F12 на каждое окно** по порядку, пока не останется чистая карта. Записать словами, что было (ожидаем: окно
   передачи хода Империи, затем «Начало задания, день N»; окна выбора навыка лидера — **нет**).
4. «Конец хода» за Империю и за Эльфов. В начале следующего хода Империи — F12 на окно выбора навыка (ожидаем: теперь оно есть).

## Часть 2. Окно защитника (15 мин)

1. Вести отряд одной расы к отряду другой (или к её столице), пока не сможет напасть.
2. Напасть. **F12 в момент, когда появится любое окно перед экраном боя** (ожидаем: «… атакован! Вы должны защищаться!» с
   портретом защитника). Окна нет — F12 на первый кадр экрана боя.

## Часть 3. Автобой (5 мин)

1. В том же бою нападающий включает «Автоматическое управление».
2. Смотреть: когда ход доходит до юнита защитника — ждёт ли игра щелчка (ожидаем: ждёт; у защитника переключатель выключен).
   F12 в этот момент. Записать словами.
