## Как считалось

- **Опись** — `tools/d2probe/coverage/functions.tsv`: 22 353 «надёжных» начала функций (цель прямого вызова, запись vtable или
  указатель), область и класс-хозяин — `tools/port_status_count.py`. Исполнено 16 300 (72,9 %); три адреса первой партии
  (`0x5486e8`, `0x5486f2`, `0x6063b5`) — настоящие начала из 11, снятых со списка после краха, в опись не входят.
- **Вторая партия шла с исправленным списком:** в заголовке `.cov.txt` `armed 22353`; `probe_coverage.py check-list` по
  `game-pristine` — «не начало инструкции 0»; ни один из 11 снятых адресов (`0x46464d`, `0x58444e`, `0x5c3a58` и др.) в ней не исполнен.
  Порчи кода нет, исключений из сверки не нужно.
- **Уровень сверки функции** (`tools/coverage_map.py`): адрес внутри функции (от её начала до следующего начала описи) стоит
  - в тесте (`src/*.Tests`, `tests/`) — «харнесс»;
  - в коде порта (`src/D2.Data`, `src/D2.Rules`, `godot/`) — «порт»: поведение перенесено по листингу и проверяется харнессами области
    по журналам;
  - только в `docs/` — «доки»;
  - адреса нет, но класс-хозяин назван в коде порта — «класс»;
  - класс — перечисление из таблиц (`LAttackClass`, `LRaceCategory` …) — «перечисление»: в порту это данные, не код;
  - иначе «нигде».
- **Где исполнилось впервые** — по `seq` первого исполнения из `.cov.txt` и журналу той же партии: бой, ход ИИ, ход человека
  (последнее окно), запуск и меню. «Нигде» в бою и в ходе ИИ — код, исполненный внутри эпизода, который сверяется поведением:
  все бои корпуса — С1/С2 (С1 94 273 сверки формул, 0 расхождений; С2 1091/1091 боёв, в этой партии 72 из 75, 3 пропуска известной
  причины), ходы ИИ — харнессы тактики, стратегии, дипломатии и мест (разбор, таблица 1).
- **Оговорки.** Адрес вызова внутри большой функции засчитывает её целиком (оценка сверху для «харнесс»/«порт»); класс по имени —
  грубая оценка в обе стороны: имя класса может встретиться в порту и без переноса всего класса, а перенесённый класс порт часто
  называет по правилу, а не по имени. «Не исполнено» — только про эти две партии: корпус (36 каталогов, с
  синтетическими картами 1–22) шире. Пример — атаки боя (строки `attack_new` по классу атаки): Двойник 60 атак в корпусе / 0 в партиях
  покрытия, превращение себя 60 / 0, призыв 320 / 0, окаменение 92 / 0, вытягивание уровня 30 / 0, дар атаки 92 / 0, обереги 46 / 0,
  ожог 36 / 0, мороз 30 / 0, разрушение брони 11 / 0, воскрешение 9 / 0 — эти бои уже сверены С2, не хватает только адресов.

## Что сыграть дальше (синтетические карты под неисполненный код)

Самое дешёвое — **сыграть уже готовые карты с покрытием**: карты 19–22 ждут партии (`install.py --vanilla-globals --coverage` вместо
обычной установки), карты 3, 7, 9, 11, 12 (события и магия) сыграны без покрытия. Объединённый `.cov.txt` покажет, что остаётся.
Новые карты — по весу групп выше:

1. **К1 «все атаки боя»** (~250 функций боя): арена, где у человека по отряду с каждым классом атаки, которого не было (Двойник,
   превращение себя, призыв, вытягивание уровня, окаменение, ослабление урона и инициативы, воскрешение, разрушение брони, дар атаки,
   ожог, мороз, обереги, страх, вампиризм с избытком), и бои, где человек перетаскивает зелье, сферу и талисман на юнита, жмёт «ждать»,
   «пропустить», бежит, включает автобой.
2. **К2 «события: все условия и эффекты»** (~300): по событию на каждое условие (`L_OWN_ITEM`, `L_LEADER_OWN_ITEM`, `L_ITEM_TO_LOCATION`,
   `L_LEADER_TO_CITY`/`ZONE`, `L_VISIT_SITE`, `L_ALLIANCE`, `L_DIPLOMACY`, `L_KILL_STACK`, `L_VAR_IN_RANGE`, `L_ENTER_CITY`,
   `L_TRANSFORM_LAND`) и эффект (литьё на карте, смена владельца, перенос и перенос рядом, дипломатия, союз, ориентиры, предметы и
   заклинания, переменные, горы, цели, бой, смена земли, снятие отряда, развеивание тумана, смена приказа, победа, включение события).
3. **К3 «ИИ у мест и по приказам редактора»** (~160): лагерь наёмников, храм и маг на пути ИИ, ИИ-вор рядом с торговцем, призывы ИИ,
   отряды с приказами AttackParty, DefendParty, Guard, MoveToStack, MoveToLocation/Zone, мешки для Roam, раненые ИИ у своих крепостей,
   союз ИИ ↔ ИИ на разрыв (карты 20–22 закрывают часть — сыграть их с покрытием).
