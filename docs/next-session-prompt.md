**Правила.**
- Закреплённые числа не подгонять: меняются только с разбором и проверкой «старое правило → прежние числа»; переключатель удалить до
  коммита.
- Рабочие копии git сносить только `python tools/wt_remove.py <путь> --branch`. Никаких symlink/junction: данные — `D2_CORPUS_DIR` /
  `D2_ASSETS_DIR` / `D2_GAME_DIR`. `corpus/` и `TestResults/` не коммитить. Подагентам повторять эти правила.
- Не править файлы сессий Б, В и Г (`godot/scenes/**`, `data/ui/**`, `src/D2.Data/Ui/**`, события сценария, импорт сценариев) — см.
  `docs/parallel-sessions.md`; при слиянии — чинить конфликт и то, что сломалось, в любых файлах.
- `dotnet test` запускать с `DOTNET_CLI_UI_LANGUAGE=en` — вывод бывает русским, и фильтры (`Passed!`, `Expected`) его не видят. Не
  запускать два `dotnet test` в одной копии; полный прогон ~4 мин — в фоне.
- Heredoc в Git Bash теряет бэкслеши и `\n` — скрипты правки писать Write-инструментом в scratchpad; рабочая копия в CRLF: образцы искать
  с концом строк файла. `git stash` не использовать.
