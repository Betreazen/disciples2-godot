## 6. Точка отмены: герой не ходит

Факты (все 11 журналов): ходит только бес; `turn_after.next` от самого движка после каждого хода
беса — снова бес; `currentRound` не растёт; очередь `order = [S143UN0007/1, S143UN0013/1]`
статична; статусы героя чисты (`st = st2 = 0`, `flags = 10` = `indexInGroup=2 + attacker`,
битов `Retreat`/`Paralyze`/`Petrify`/`waited` нет); скрытых бросков и событий между ходами нет.
По правилам игры герой с уроном 50 убил бы беса (65 HP) за два хода.

Гипотезы, ранжированные двумя независимыми ревью (`task-5-report.md`, план «Ход исполнения»):

1. **~0.85 — артефакт принудительного автобоя зонда.** Хуки `isAutoBattle`/`isFastBattle` отвечают
   `true`, не вызывая оригинал (README зонда, «Автобой»); все журналы сняты с маркером
   `probe/autobattle`; `autobattle_forced` стоит ровно между двумя вызовами `beforeBattleRound`
   раунда 1; флаг в `BattleMsgData` не выставлен, у стороны человека нет источника действия.
2. **~0.12 — настоящее правило движка** о ходах стороны без «готового» действия — проверить нечем,
   корпус однороден.
3. **~0.03 — групповое отступление**, решённое ИИ за человека (`BattleStateFlags.attackerRetreatStatus`
   в журнал не пишется). Против: нет бита `Retreat`; раунд закончился бы после одного хода беса, а
   не семи.

Решение контроллера: причина найдена с высокой вероятностью и проверяется одним прогоном без правки
кода; журнальный С2 5/5 показывает, что формулы, генератор, урон, условие конца боя и победитель
верны, поэтому T6/T8 (не зависят от выбора ходящего) выполнены, не дожидаясь прогона. Строгий С2
остаётся Skip «точка отмены» до нового корпуса; окончательное решение — за пользователем.

## 7. Инструкция пользователю: проверочный прогон

Один прогон, без правки кода (из плана, «Ход исполнения»):

1. `python tools\d2probe\install.py` — **без** `--autobattle`: маркер `probe/autobattle` снимается,
   хуки режима боя не ставятся.
2. `python tools\gamedrv\goto_battle.py` — игра доходит до боя и остаётся открытой.
3. В бою нажать кнопку автобоя самой игры (или сходить героем вручную), дождаться конца, выйти.
4. `python tools\corpus_run.py --dry-run --from-file <игра>\probe\<новый>.jsonl --out corpus\20260906-manual` (с `--resume`, если каталог уже есть)
   и `dotnet test`.

Чтение результата:

- **герой ходит** → гипотеза 1 подтверждена: корпус 06.09 годен для формул и RNG, но не для очереди;
  дальнейшие прогоны идут без маркера (автобой кнопкой). Затем корпус по плану: сценарии `_a.._e`,
  ≥ 5 каталогов × ≥ 10 боёв с различающимися составами, `dotnet test` — `C2_ReportsReproductionRate`
  выходит из Skip, `C2_AtLeast99PercentOfBattlesReproduce` считает K/N при N ≥ 10 (порог фазы — N ≥ 50).
- **герой не ходит** → гипотеза опровергнута; разбор `CBatLogic` рядом с `0x62481a` (кто выбирает
  `nextUnitId`).

## 9. Реализовано / не реализовано

Реализовано (`src/D2.Rules`): `EngineRng` (R250, `Fit`, `Advance`), `IRng`/`ScriptedRng`;
`Formulas` (6 формул + `CriticalDamage`); `TurnOrder`; `BattleSim` (раунды, очередь, `Act`,
`Winner`, очередь нового раунда до решения о конце боя); `Attacks.Apply` — `Damage` (ранг 1),
`Heal`, `Paralyze`, `Poison`/`Frostbite`/`Blister` (DoT) — ранг 3; `Fear` после ревью T6 не реализован (`NotSupportedException`, отступление — Ф6); двойная атака (ранг 2), перенацеливание второго удара после гибели цели — ранг 3;
харнессы С1/С2; сцена `godot/BattleReplay` (проигрывание журнала, headless `turns: N`).

`easy`, модификаторы `getAttackPower`, дальность и крупные юниты, `maxRounds`, опыт, ход по клику
мышью (сцена только проигрывает журнал), С3.
