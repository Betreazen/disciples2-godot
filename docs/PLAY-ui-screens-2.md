# Прогон с зондом: срез экранов интерфейса, часть 2

Продолжение `docs/PLAY-ui-screens.md`. После среза 19.09 не открывались 15 нужных порту экранов:
конец сценария и главы кампании, импорт и экспорт героя, кража заклинания, окно посоха, окна правой
кнопки по игроку, руине и земле, панель «Земля», сводка хода. Где и когда игра их показывает,
выяснено по коду `Discipl2.exe` (разбор — в отчёте к срезу, адреса — в шапках `make_map.py`), и под
них собраны четыре карты и одна своя кампания. Каждый открытый экран даёт переходы в граф без ручной
работы: после прогона журнал разбирает `dotnet run --project tools/UiFlowImport`.

Четыре захода по 10–20 минут, играть можно в разные дни. **Порядок заходов 2 и 3 важен:** заход 2
экспортирует героя, и только после этого в заходе 3 заработает «Импортировать героя».

## Перед началом (один раз)

- Зонд стоит (`game-dev`, таблицы игры штатные — `python tools/d2probe/install.py --status` из
  `disciples-godot`, 19.09). Ничего ставить не нужно.
- Карты уже лежат в игре: `game-dev\Exports\ui-end-win.sg`, `ui-end-lose.sg`, `ui-misc.sg` (список
  «Новый квест») и `game-dev\Campaign\ui-camp.csg` (список «Новая своя кампания»).
- Запуск записи — PowerShell, из корня `disciples-modding`, **один раз на весь заход**:

  ```
  python tools\gamedrv\passive_run.py --out ..\disciples-godot\corpus\20260922-ui
  ```

  На следующие заходы — тот же каталог (первый прогон 19.09 записан в `20260921-ui`).
- Правило то же: **открыть окно и закрыть его той кнопкой, которой обычно закрываете**; где кнопок две —
  по возможности открыть дважды и нажать обе.
- Окно не открылось, открылось не то, игра упала — запишите одной строкой. Это тоже ответ.
- Карты скрипт в игре не запускал: **первый запуск — ваш**. Если карты нет в списке или игра падает при
  выборе — напишите и эту карту дальше не играйте.

У каждой карты своя подробная памятка — `tools/ui-maps/<карта>/player-memo.txt`; ниже — сжато.

## Чего в этой памятке нет и почему

- **`DLG_CHOOSE_CAMPAIGN`** (выбор кампании) и **`DLG_COMMON_RECAP`**: в `Discipl2.exe` есть только
  строки с их именами — ни один код на них не ссылается, в версии 3.01 эти окна не показываются. Потому
  «Новая сага» и сразу ведёт к выбору расы.
- **Импорт героя в саге**: кнопка активна только в кампаниях с разрешённым импортом (`CANIMPORT` в
  `Campaign\CCamp.dbf`): квесты и свои кампании (C000CC0001) и четыре кампании «Стражей Света»; в
  исходных сагах и в кампании эльфов — нет.
- **`DLG_R_C_TRANSFORM`** (земля расы): окно создаётся только для подсказки особого вида, а такую
  подсказку, по коду, никто не создаёт. Шаг 7 захода 3 — дешёвая проверка; не откроется — ожидаемо.
- **Сетевые экраны** — порту не нужны.
