# Аудит порта против `Discipl2.exe` (13.10.2026)

Независимая проверка «весь ли код перенесён и правильно ли». Отчёты подагентов по областям — `.analysis/audit/*.md` (вне git,
на этой машине); здесь — итог, что исправлено и что осталось.

## Метод

- **Опись движка** — 2370 классов RTTI из `Discipl2.exe` (REA 6.4.0 поверх Ghidra 12.1.4, `docs/re-tools.md`) и значения
  перечислений `L*.dbf`. Это полный перечень подсистем оригинала: команды игрока (`CCmd*`, `C*Msg`), изменения мира
  (`CVisitor*`), эффекты исполнения (`CEffect*`), условия и эффекты событий, ИИ (`CAi*`), бой (`CBat*`), окна (`C*Interf`).
- Каждый класс и значение сопоставлены с кодом порта и оценены по доказательству: **A** — харнесс по журналу зонда или
  корпусу, **B** — юнит-тест на ручных ожиданиях, **C** — только документ или листинг, **D** — ничего.
- Около двадцати выборочных сверок псевдокода движка с кодом порта через REA.
