# Реестр расхождений порта с оригиналом (на 18.10.2026)
Все расхождения порта с `Discipl2.exe`, которые нашла сверка с 13.10.2026: журналы зонда, синтетические карты 1–15, харнессы, аудит
по листингу и партии пользователя. Раньше 13.10 расхождения разбирались по фазам Ф0–Ф7; они закрыты и сюда не входят
(`memory` «История переноса»). Карты 13–15 (партия 18.10) и номера id (`r18/ids`) внесены по разборам 18.10.

- прогон тестов 18.10 (`docs/port-status-20261018.md`, «Как получены числа»).
Если расхождение есть в нескольких источниках, оно записано одной строкой. Если один коммит закрыл несколько разных расхождений, каждое
записано своей строкой.
**Статус** — первое слово последней колонки:
- **исправлено** — порт приведён к движку. Указан коммит или ветка, а для правок «по листингу» — адрес; есть ли сверка журналом, сказано рядом.
- **не баг** — так у движка (адрес или журнал), либо это артефакт харнесса, карты или окружения, а порт верен.
- **открыто** — расхождение есть или не объяснено; рядом сказано почему.
- **не проверено** — подозрение только по листингу, в журналах случаев нет.
- **исключено** — не учитывается по договорённости 18.10 (раздел «Не учитываем»): сеть и чат, решения пользователя, устройство порта, окружение оригинала.
Пересчёт итогов: `python tools/divergence_ledger_count.py` — он печатает таблицы раздела «Итог» из строк реестра.
