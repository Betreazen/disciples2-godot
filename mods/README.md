# Моды

Каждый подкаталог с `mod.json` — слой поверх базового набора `data/`. Формат, разобранный пример и
проверки — [docs/modding.md](../docs/modding.md).

Этот каталог — для разработки; моды игрока лежат в `user://mods`
(`%APPDATA%\Godot\app_userdata\Disciples\mods`). Слои отсюда включены при обычном запуске и выключены
у проверок (`--no-mods`). Поэтому здесь — только слои, нужные игре (`port-synth` — синтетические карты); примеры —
в `_examples` (не включены, `--mods ../mods/_examples`). Заменённый экран обязан сохранить все элементы базового — иначе
окно игры не откроется (тест `DefaultMods_KeepEveryElementOfReplacedScreens`).
