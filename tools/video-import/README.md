# Ролики игры: Bink → Ogg Theora + опись

Порт не должен в рантайме знать Bink (`.bik`). Ролики переводятся один раз этим инструментом в Ogg Theora
(`.ogv`, видео Theora, звук Vorbis): файлы ложатся на диск, а в git коммитится только опись — по ней порт
находит ролик по имени и проверяет, что грузит.

**Почему Theora.** Это единственный видеоформат, который Godot 4 проигрывает сам (`VideoStreamTheora`),
без расширений и сторонних библиотек. Качество `-q:v 8` из 10: кадры, декодированные самим Godot, совпадают с
кадрами Bink на 33–38 дБ PSNR (разница в основном от перевода YUV→RGB), на глаз потерь нет.

## Пересборка

```
python tools/video-import/build_videos.py
```

Игра берётся из `D2_GAME_DIR` (по умолчанию `C:\Claude code projects\disciples-modding\game-pristine`),
ffmpeg и ffprobe — из `FFMPEG` и `FFPROBE` (по умолчанию из `PATH`):

```
FFMPEG=/путь/ffmpeg.exe FFPROBE=/путь/ffprobe.exe python tools/video-import/build_videos.py
```

Прогон занимает ~45 с (ролики кодируются параллельно, по одному на ядро). Распаковщик `MenuAnim.ff` —
`tools/ui-assets/ff_extract.py` (класс `FFArchive`, без изменений): записи `.BIK` в архиве лежат целиком.

**Не всякий ffmpeg годится.** Сборка ffmpeg 8.1 (gyan.dev; стояла в `C:\ffmpeg\bin` до 19.09.2026, теперь
отложена в `C:\ffmpeg\bin-8.1`) пишет межкадровые блоки
Theora неверно: такой `.ogv` не читает ни декодер ffmpeg (`error in unpack_block_qpis`), ни Godot (кадры
рассыпаются, PSNR ≈ 8 дБ). Поэтому инструмент сначала кодирует пробный ролик и читает его обратно — при любой
ошибке отказывается работать. ffmpeg 9.0.1 (gyan.dev, релиз `GyanD/codexffmpeg`, sha256 архива сверен с релизом) кодирует правильно; с
19.09.2026 он стоит в `C:\ffmpeg\bin`, и опись, пересобранная им из `PATH`, совпала с прежней байт в байт.

## Что получается

| Куда | Что | В git |
|---|---|---|
| `assets/video/<Источник>/<ИМЯ>.ogv` | ролики | нет (`.gitignore`, `/assets/`) |
| `assets/video/Briefing/BRIEFEL<N>.ogg` | озвучка брифингов кампании эльфов | нет |
| `data/video/videos.json` | опись: имя, источник, путь, размер, fps, кадры, длительность, звук, короткий sha256 | **да** |

Всего 110 записей, ≈200 МиБ.

| Источник | Откуда | Записей | Размер, fps | Объём |
|---|---|---|---|---|
| `MenuAnim` | `Interf/MenuAnim.ff` | 52 | 800×600 и 197×347 (лица), 15 | 18 МиБ |
| `Briefing` | `Briefing/*.bik`, `*.wav` | 42 ролика + 8 `.ogg` | 640×360, 15 | 156 МиБ |
| `Video` | `Video/*.bik` | 8 | 640×360 и 800×600 (`CREDITS`, `SF`), 15 | 27 МиБ |

Имена — ВЕРХНИМ регистром без расширения (`TRANS_MAIN2SINGLE`, `BRIEFH01`, `INTRO`), уникальны во всех
источниках. Все числа — из исходного `.BIK` (ffprobe), sha256 — тоже от исходника: опись воспроизводится
байт-в-байт при любой версии ffmpeg. `frames` — кадры Bink; в `.ogv` неизменный кадр записан пустым пакетом
(«повторить предыдущий»), так что сверять с описью надо по пакетам, а не по декодированным кадрам.

Прозрачности в роликах нет: у всех Bink формат `yuv420p` без альфа-плоскости, мадженты (255,0,255) и
зелёного ключа нет ни в одном пикселе (проверены все кадры `MenuAnim`, `CREDITS`, `SF`, `BRIEF2D`, `DEFAULT`).

## Что за ролики

**`MenuAnim`** — анимация меню, всё 800×600 кроме лиц:

- `TRANS_A2B` — переход между экранами меню A и B (`TRANS_MAIN2SINGLE` — главное → одиночная игра,
  `TRANS_SINGLE2GOD` — к выбору расы, `TRANS_BLACK2MAIN`, `TRANS_INTRO2MAIN` — вход в главное меню). 15–31 кадр.
- `GOD_X2Y` — смена расы X→Y на экране выбора бога (`HU` Империя, `DW` Горные кланы, `UN` Нежить, `HE` Легионы
  проклятых, `EL` Эльфы). 30 кадров. Пар 10 — только соседние по кругу HU→HE→DW→EL→UN→HU, в обе стороны.
- `TRANS_GOD2LORD_X` — переход от выбора расы X к выбору лорда.
- `FACE_XX_N` — лицо лорда расы XX, вариант N (0–3), 197×347, 12 кадров.
- `NOIR` — один чёрный кадр 32×32 (заглушка; частота 50000/3333 ≈ 15.002).

**`Briefing`** — брифинги кампаний: `BRIEF<раса><NN>` (по букве, видимо, `H` Империя, `L` Легионы, `M` Горные
кланы, `U` Нежить; 01–07) — ролики со звуком, 47–87 с. `BRIEF2*`, `BRIEF3EL`, `CMP2*`, `DEFAULT`, `DEFLOSE`, `DEFWIN`, `ELFWIN` —
неподвижные картинки в один кадр (фон брифинга, победы, поражения). `CMP3EL` — ролик без звука (1570 кадров).

`briefel1.wav`…`briefel8.wav` — озвучка брифингов кампании эльфов: внутри `.wav` MP3 (44.1 кГц, стерео,
66–108 с), картинки к ним нет — её, видимо, даёт неподвижный `BRIEF3EL`. Это просто звук, поэтому он переводится
в Ogg Vorbis (`.ogg`) и попадает в ту же опись с нулевыми `w`, `h`, `fps`, `frames` (`UiVideo.HasVideo` —
`false`). Длительность у них посчитана по пакетам MP3: заголовок WAV занижает её на ≈0.5 с.

**`Video`** — `INTRO` (вступление, 63 с), `CREDITS` (титры, 800×600), `SF` (800×600, 8 с, со звуком),
`CONC<раса>` — концовки кампаний (`CONCEL` — один кадр).

## Кто это читает

`src/D2.Data/Ui/UiVideos.cs` — чтение описи, `ByName` без учёта регистра, `PathOf` для пути к файлу, `Merge`
для модов (замена по имени, как `UiAssets.Merge`). Проверки — `src/D2.Data.Tests/UiVideosTests.cs`; сверка
файлов с описью (заголовки Theora/Vorbis: размер и частота кадров) пропускается, когда `assets/video` не собран.
