# Графика карты и боя: архивы `Imgs/*.ff` → WebP без потерь + опись

Порт в рантайме не знает формат `.ff` (MQDB): графика мира и боя вынимается один раз этим инструментом,
как интерфейс — `tools/ui-assets`. Картинки (WebP без потерь) ложатся на диск (вне git), в git коммитится только опись.

## Пересборка

```
python tools/gfx-assets/build_gfx_assets.py                  # все 23 архива Imgs, ~9 мин (было ~15 мин у PNG в два прохода)
python tools/gfx-assets/build_gfx_assets.py Ground GrBorder  # выборочно
```

Игра — из `D2_GAME_DIR` (по умолчанию `disciples-modding/game-pristine`), выход — `D2_ASSETS_DIR/gfx`, если переменная
задана, иначе `assets/gfx`. Нужны Pillow с WebP и numpy. Распаковщик — `tools/ui-assets/ff_extract.py`: главный процесс
читает только оглавления архивов, кадры собирает и кодирует пул процессов на все ядра кусками по 256; архив процессы
читают отображением файла (страницы общие — прежний `MemoryError` от 23 копий архивов в памяти не грозит).

Ключ прозрачности вырезается **при записи каждого кадра** (`tools/ui-assets/keyed_webp.py`), отдельного второго прохода
нет. Сборка идёт во временный `assets/gfx.new`; в конце выборка файлов разбирается заново и сверяется с хешем описи, и
готовый каталог встаёт на место переименованием (выборочная сборка — каталоги собранных архивов по одному), затем
заменяются описи. Прерванная сборка или запуск игры посреди неё оставляют прежнюю целую графику; пурпурных файлов на
диске не бывает ни в какой момент. Прервались ровно между двумя переименованиями — прежний каталог (`gfx.old`) вернёт
следующий запуск сборщика.

## Что получается

| Куда | Что | В git |
|---|---|---|
| `assets/gfx/<Архив>/frames/<ИМЯ>.webp` | отдельные кадры, RGBA | нет |
| `assets/gfx/<Архив>/anims/<АНИМ>/NNN_Х.webp` | кадры анимаций по порядку, RGBA | нет |
| `assets/gfx/<Архив>/plain/<ИМЯ>.webp` | самостоятельные картинки (земля, лица, значки); листы-атласы не пишутся | нет |
| `assets/gfx/<Архив>/manifest.json` | разбор архива (кадры, куски, `opacity`) для режима `--opacity` | нет |
| `data/gfx/<Архив>.json` | опись архива: картинки (имя, путь, размер, хеш) и анимации (каталог, имена кадров, хеш) | **да** |

Сборка 11.10.2026: **23 архива, 2446 картинок, 134 210 кадров анимаций, 728 МБ WebP** (было 2,6 ГБ PNG вместе с
листами-атласами), описи — ~3 МБ (`BatUnits` 1,4 МБ: 4912 анимаций юнитов боя, `IsoUnit` 1,0 МБ).

## Чем отличается от интерфейсного конвейера

- **Прозрачность запечена.** Маджента (RGB565 0xF81F) — ключ прозрачности игры — при записи кадра становится альфой 0
  (и цвет обнуляется, чтобы при фильтрации не было розовой каймы). Порт грузит файлы как есть. Ключ кадров из листов-атласов —
  ещё и **индекс палитры `transparent_index`** из `-IMAGES.OPT` независимо от его цвета (`ff_extract.base_image`): у 85 групп
  `palette[0]` чёрный, и без этого правила атака гоблина (`G000UU5017HMOVA1*`), лодки `IsoUnit`, часть заклинаний `IsoSpell` шли в
  непрозрачных чёрных прямоугольниках (пункт 2 прогона 2, 11.10; разбор — `disciples-modding/docs/level2-rasterizer-spec.md` §10).
- **WebP без потерь** (`lossless`, `exact`, `method` 4): пиксели после разбора бит в бит те же; замер выбора — `docs/perf-log.md` Г6.
- **Анимация — одна запись описи** со списком имён кадров и расширением (`ext`): опись по кадру раздула бы файл до мегабайтов.
- **Хеш — от пикселей**, не от байтов файла: опись не зависит от кодека (у прежних PNG и нынешних WebP хеши те же).
- **Кадр — только занятая часть холста** (Г19, `docs/perf-log.md`). Кадры карты и боя — холсты 320×320…800×600 вокруг якоря,
  занято в среднем ~12 % точек. Если занятый прямоугольник (альфа не 0) не больше половины холста, в файл идёт только он, а в опись —
  угол `at` в холсте: у картинки `[x, y]`, у анимации `[x0, y0, x1, y1, …]` по кадрам; `w`, `h` — по-прежнему холст, хеш — от холста
  (у обрезанной и прежней целой сборки хеши те же). Правило — как у рантайма `GfxTextures.Trim` (Г7): текстура на экране та же, только
  без разбора холста и поиска занятой части. Нет `at` (моды с целыми холстами, анимация с кадрами разного холста — одна в `IsoSpell`) —
  обрезает рантайм, как прежде. Кто смотрит точки в координатах холста, берёт `GfxTextures.Canvas`. Интерфейс (`tools/ui-assets`) не
  обрезается: его картинки рантайм берёт целыми. Сборка 14.10: обрезано 133 262 кадра из 136 656 (97,5 %), WebP 616 → 597 МБ, описи
  3,1 → 4,3 МБ.
- Листы-атласы, из которых движок режет кадры, в опись не входят (порт берёт готовые кадры); самостоятельные
  картинки — входят (у `Ground`, `Faces`, `GrBorder`, `IconBld`, `PalMap` кадров нет вовсе).

## Кто читает

`src/D2.Data/Gfx/GfxAssets.cs` — опись, поиск по паре «архив + имя» (имена в разных архивах повторяются), слой
модов (`data/gfx/*.json` мода, файлы — его `assets/gfx`). Проверки — `GfxAssetsTests`.

Землю карты движок из этих картинок **собирает**, готовой её в архивах нет — см. `docs/ground-render.md` и
`src/D2.Data/Gfx/GroundComposer.cs`; стенд — `godot/scenes/dev/GroundTest.tscn`.
