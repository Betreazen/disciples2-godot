# UiStringsImport — строки интерфейса из таблиц игры

Переводит текстовые таблицы исходной игры (`Globals/Tglobal.dbf`, `Interf/TApp.DBF`, cp866) в данные порта
`data/ui/strings.<язык>.json`. Файлы лежат в git: это данные порта, а не кеш. В рантайме порт читает
только их — `.dbf` нужен здесь и больше нигде.

Подробности (что за таблицы, какие языки, чего в них нет) — `docs/ui-text.md`.

## Пересборка

```sh
dotnet run --project tools/UiStringsImport -- --lang en
dotnet run --project tools/UiStringsImport -- --lang ru
# свои пути и слои:
dotnet run --project tools/UiStringsImport -- --lang de --from "C:/…/game-de" --out data/ui/strings.de.json
```

`--from` можно повторять: слои накладываются по порядку, последний выигрывает. Без `--from` корни берутся
по умолчанию (`UiStringsImport.DefaultRoots`):

| Язык | Корни |
| --- | --- |
| `en` | `GamePaths.GameDir` (переопределяется переменной среды `D2_GAME_DIR`) |
| `ru` | то же плюс `disciples-vanilla/l10n/russobit` — слой русификации с теми же идентификаторами |

Сейчас на выходе **3284 строки** в каждом языке: 2292 из `Tglobal` и 992 из `TApp`, пересечений нет.
`strings.en.json` — 176 КБ, `strings.ru.json` — 261 КБ.

Перевод повторяем: те же исходники дают тот же текст байт в байт. Это проверяет
`UiStringsTests.Strings_Json_IsUpToDate` — если таблицы или правила импорта изменились, а файл не
пересобран, тест падает и называет первую разошедшуюся строку. Тест пропускается, когда исходников
на машине нет.

## Формат

Плоская таблица «идентификатор → текст», ключи отсортированы (иначе дифф прыгал бы от порядка записей
в dbf), идентификаторы приведены к верхнему регистру:

```json
{
  "X000TG0000": "Империя",
  "X100TA0020": "Закрыть"
}
```

Пометки переводчиков из таблиц (`VERIFIED`, `CONTEXT`) в порт не переносятся.

Разметка внутри текста (`\c000;000;000;\hC;\fLarge;Неудача!`, `\n`, `%NAME%`) сохраняется как есть:
разбирает её при отрисовке `D2.Data.Ui.UiTextStyle`, а подстановки заполнит логика игры.

## Как мод меняет строки

Мод кладёт рядом свой файл — только те строки, которые меняет, — и он накладывается поверх по
идентификатору:

```csharp
var strings = UiStrings.Merge(
    UiStrings.Load("data/ui", "ru"),
    UiStrings.LoadFile("mods/мой-мод/ui/strings.ru.json"));
```

Целый новый язык — это просто ещё один файл `strings.<код>.json`: `UiStrings.Load` возьмёт его, а всё
непереведённое доберёт из английского.
