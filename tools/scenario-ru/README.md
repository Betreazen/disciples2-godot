# Перевод сценариев на русский

Перевод сценария — языковой слой `data/scenarios/lang/<язык>/<сценарий>.json` поверх английского файла
`data/scenarios/<сценарий>.json`, который не правится (`D2.Data.Play.ScenarioTexts`). Игра берёт слой по `--lang`
(по умолчанию `ru`); нет файла, ключа или текст пуст — показывается оригинал. Мод кладёт свой слой в
`<мод>/data/scenarios/lang/<язык>/` — его ключи перекрывают базу.

## Откуда текст

| Источник | Сценарии | Как обновить |
| --- | --- | --- |
| `Руссобит-М` — русское издание (`disciples-vanilla/l10n/russobit`: `Exports/*.sg`, `Scens/Sinfo`, `Scens/Tscen`) | 27 квестов, 48 глав саг | `dotnet run --project tools/ScenarioImport -- --texts ru` |
| `машинный перевод` — переводчик порта | 6 квестов GOG, которых нет в русском издании (`'A Return To Simpler Times'`, `'The Seals'`, `'Vertigo'`, `'Greenskins'`, `'Orc Champion'`, `'Orc Champion_advanced'`) | `extract.py --merge` |

Текст Руссобит-М руками не правится: тест `ScenarioTextsTests.Russobit_Texts_AreUpToDate` сверяет его с импортом.
Пропуски издания (текст не переведён — совпадает с английским, или вместо текста id поля `NAME_TXT`) импорт
оставляет пустыми; дописанное в них переводчиком порта импорт сохраняет.

## Формат файла

```json
{
  "Format": "d2-port-scenario-texts",
  "Version": 1,
  "Id": "Hatred",
  "Language": "ru",
  "Source": "Руссобит-М",
  "Texts": {
    "name": "Ненависть",
    "event:S073EV0002:0": "Брадобар \n\"Король Вирджил разбил армию Орков…\""
  }
}
```

`Id` — имя файла сценария без `.json`. Ключи `Texts` (порядок — как в сценарии):

| Ключ | Поле | Где видно |
| --- | --- | --- |
| `name`, `description`, `briefing`, `briefingLong`, `winText`, `loseText` | карточка сценария (`data/game/scenarios.json`, главы — `campaigns.json`) | выбор сценария, брифинг, «Задание», эпилог победы и поражения |
| `player:<id>` | имя лорда игрока | дипломатия, сообщения |
| `site:<id>:name`, `site:<id>:desc` | город, лавка, маг, наёмники, тренер, руина | подписи на карте, окна объектов |
| `stack:<id>` | имя лидера отряда | карточка отряда, сообщения |
| `template:<id>` | имя лидера отряда, которого создаст событие | то же |
| `event:<id>:<n>` | текст n-го эффекта события: окно (`L_POPUP`) или новая цель (`L_CHANGE_OBJECTIVE`) | окно события, «Задание» |

Имена событий, областей и переменных — служебные (редактор), их нет в слое.

## Инструменты

```sh
py tools/scenario-ru/extract.py --stats                              # сколько переведено, по сценариям
py tools/scenario-ru/extract.py "'Greenskins'" --out todo.json       # {ключ: английский} без перевода
py tools/scenario-ru/extract.py --merge done.json "'Greenskins'"     # влить {ключ: перевод} в слой
py tools/scenario-ru/extract.py --reuse "'Orc Champion'" "'Orc Champion_advanced'"  # перенести перевод варианта карты
py tools/scenario-ru/check.py [--complete] [сценарий ...]            # валидность и полнота
py tools/scenario-ru/glossary.py                                     # пересобрать glossary.ru.json
```

`check.py`: ошибки — чужой ключ, пустой текст, потерянная подстановка `%ИМЯ%`, не тот `Id`/`Language`; предупреждения —
нет кириллицы, пропала строка говорящего, пропало число, другое число абзацев, текст длиннее самого длинного у
Руссобит-М того же поля, «ё» или «—».

## Словарь — `glossary.ru.json`

`races`, `lords`, `units`, `spells`, `items`, `landmarks`, `buildings` — имена из таблиц игры по строкам интерфейса
(как в карточках и окнах); `names` — имена собственные из текстов Руссобит-М (город, лавка, лидер), самый частый вариант;
`lore` — боги, народы, герои; `phrases` — повторяющиеся реплики торговцев и эпилоги.

## Правила стиля (по текстам Руссобит-М)

- **Имя типа юнита** в имени лидера или шаблона и в строке говорящего — как в интерфейсе (`units`): Squire — «Сквайр»,
  Orc Champion — «Орк-багатур», Cleric — «Монахиня», Rock Giant — «Горный великан». Расы и боги — `races`, `lore`:
  Highfather — «Всевышний», Bethrezen — «Бетрезен», Mountain Clans — «Горные Кланы» (раса — «Кланы Гор»).
- **Имена собственные** (люди, города, руины) — транслитерация по звучанию: Zaorish — «Заориш», Satoria — «Сатория»;
  если имя уже есть в `names` — брать оттуда. Говорящие имена и описательные названия — переводить: Abandoned Farm —
  «Заброшенная ферма», Elphina's Shop — «Лавка Элфины», Gorgon Castle — «Замок Горгон», X City — «Город X».
- **Обращение к игроку — «вы»** (у Руссобит-М «вы» вдвое чаще «ты»); «ты» — у грубых и надменных персонажей (орки, демоны,
  наёмники, злодей к герою). «Milord» — «Милорд», «my Lord» — «милорд».
- **Разметку не трогать**: строка говорящего `Имя \n"реплика"` (имя, пробел, `\n`, реплика в прямых кавычках `"`),
  переводы строк `\n`, `\r`, абзацы `\n \n`, знак `_` в карточке (служебная пометка редактора внутри слов — оставить
  примерно на том же месте), подстановки `%ИМЯ%`, числа и проценты.
- **Регистр**: названия народов и богов с большой буквы, как у Руссобит-М («Империя», «Кланы», «Нежить», «Проклятые»);
  в именах типов юнитов — как в интерфейсе (обычно с маленькой второе слово: «Белый медведь»).
- Без «ё» (в строках интерфейса и у Руссобит-М её нет) и без длинного тире «—»: тире — «–» или « - », как у Руссобит-М.
- Стиль — фэнтези без канцелярита и современных слов; длина — близко к оригиналу и не больше самого длинного текста
  Руссобит-М того же поля (название сценария — до 25 знаков, окно события — до ~250).
  Опечатки оригинала не переносить.
- Повторяющиеся тексты (`phrases`) — дословно как у Руссобит-М: «Поздравляем! Вы успешно справились с задачей._»,
  «Вы потерпели поражение, враг достиг своей цели.».
